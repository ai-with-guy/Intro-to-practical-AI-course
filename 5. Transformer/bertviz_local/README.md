This is the BertViz 1.4.1 head view (Apache-2.0; see `LICENSE`), kept locally
with its original controls, token hover behavior, and visualization. The only
functional changes are in `head_view.js` (use bundled jQuery/D3 rather than
`require.js`) and `head_view.py` (render those scripts in an isolated iframe).

The bundled libraries in `../bertviz_assets/` are jQuery 2.0.0 (MIT) and
D3 5.7.0 (BSD-3-Clause); their licenses are alongside the files.
